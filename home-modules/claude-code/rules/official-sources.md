# Official-Source Verification

When a question concerns the behavior, configuration, or release history of a third-party tool (e.g. Renovate,
Home Manager, GitHub Actions, pre-commit hooks, linters), do not answer from memory alone.

- Verify against primary sources before answering: official documentation, changelogs, release pages,
  or the tool's source code.
- Use web search or WebFetch when local information is insufficient.
- Name the source in the answer, and clearly separate verified facts from inference.
- If official sources do not confirm the claim, say so explicitly instead of guessing.
